## ✨ المميزات الرئيسية للنظام

### 1. واجهة المتجر والعملاء (Storefront)
- **ثيم الفخامة البيضاء (Pure White Luxury)**: خلفية بيضاء نقية (`#FFFFFF`)، خطوط وعناوين سوداء أنيقة (`#000000`)، بطاقات وحقول رمادية فاتحة هادئة (`#F5F5F5`)، ولمسات ذهبية ملكية راقية (`#C5A253`).
- **الصفحة الرئيسية (Homepage)**:
  - بانر ترويجي رئيسي (Hero Section) مع زر "تسوق الآن".
  - أقسام وتصنيفات العطور (رجالي، نسائي، للجنسين، نيش ملكي، مجموعات هدايا).
  - قسم العطور الأكثر مبيعاً والأعلى تقييماً.
  - كتالوج العطور الكامل مع فلاتر سريعة.
  - بانر كود الخصم الترويجي الحصري (`WELCOME10`).
- **صفحة تفاصيل العطر (Product Details)**:
  - معرض صور تفاعلي مع إمكانية التبديل بين الزوايا وصور الزجاجة.
  - الهرم العطري التفاعلي (افتتاحية العطر، قلب العطر، قاعدة العطر).
  - محدد الأحجام (50 مل، 100 مل) مع تحديث فوري للسعر والخصم.
  - شارات توفر المخزون وتركيز العطر (EDP، Extrait de Parfum).
  - زر الإضافة للسلة وزر الشراء المباشر الفوري.
  - رابط طلب سريع ومباشر عبر تطبيق واتساب.
- **سلة المشتريات (Shopping Cart & Slide-out Drawer)**:
  - سلة منبثقة وسريعة وسلسة مع إمكانية تعديل الكميات وحذف المنتجات.
  - مؤشر ذكي للشحن المجاني (يحسب المتبقي للوصول إلى حد الشحن المجاني).
  - حفظ محتويات السلة محلياً لضمان عدم ضياع المنتجات عند إعادة تحميل الصفحة.
- **صفحة إتمام الطلب السريع (Fast Checkout)**:
  - متوافقة تماماً مع السوق المصري وبدون اشتراط تسجيل حساب مسبق (Guest Checkout).
  - التحقق الفوري من صحة أرقام الهواتف المصرية (010، 011، 012، 015).
  - قائمة منسدلة لكافة محافظات مصر الـ 27 مع حساب فوري وتلقائي لمصاريف التوصيل.
  - إدخال العنوان بالتفصيل وأقرب علامة مميزة لتسهيل وصول مندوب الشحن.
  - تطبيق كوبونات الخصم والتحقق منها لحظياً من السيرفر.
  - خيارات الدفع: الدفع عند الاستلام (كاش) أو الدفع اللحظي عبر إنستاباي (InstaPay).
  - نظام حماية ضد تكرار إرسال الطلب (Anti-duplicate submission).
- **صفحة تأكيد الطلب وفاتورة العميل (Order Confirmation)**:
  - استعراض رقم الطلب الفريد فور تسجيله.
  - زر تأكيد الطلب عبر واتساب برسالة مجهزة تلقائياً.
  - زر طباعة بوليصة وفاتورة الشحن بتصميم A4 جاهز للطباعة.
- **صفحة تتبع الشحنة لحظياً (Track Order)**:
  - تتبع الطلب برقم الطلب ورقم الهاتف المسجل.
  - خط زمني تفاعلي يوضح مراحل الشحنة (جديد -> تم التأكيد -> جاري التجهيز -> تم الشحن -> تم التسليم).
- **صفحات المعلومات والسياسات**:
  - من نحن (About Us)
  - اتصل بنا (Contact Us)
  - سياسة الشحن والاسترجاع (Shipping & Returns)
  - سياسة الخصوصية (Privacy Policy)
  - الشروط والأحكام (Terms & Conditions)

  - كتابة ملاحظات إدارية داخلية خاصة بكل طلب.
  - طباعة فاتورة وبوليصة الشحن بنقرة زر واحدة.

- **إعدادات المتجر والشحن (Settings)**:

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Framework**: Next.js 16 (App Router) + React 19 + TypeScript
- **Styling**: Tailwind CSS v4 + Pure White Luxury Aesthetic
- **Database & ORM**: SQLite + Prisma ORM 6 (مستقرة وسريعة وتخزين محلي دائم `dev.db`)
- **Authentication**: JWT + HttpOnly Cookies + Bcrypt password hashing
- **Icons**: Lucide React
- **File Uploads**: Node.js Multipart File Storage (`public/uploads`)

## 🚀 تشغيل المتجر محلياً (Quick Start)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تجهيز قاعدة البيانات وتغذيتها بالبيانات الافتراضية:
```bash
npx prisma db push
npx tsx prisma/seed.ts
```

### 3. تشغيل خادم التطوير:
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 4. لبناء وتشغيل نسخة الإنتاج (Production Build):
```bash
npm run build
npm run start
```
